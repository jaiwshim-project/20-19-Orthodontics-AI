# 자동 분석 수정 → 학습 반영 순환 안내

자동 분석 그래프가 부정확할 때, 의료진이 수정한 결과를 학습에 반영해 엔진을 점진적으로 정답 수준으로 개선하는 절차입니다.

## 전체 흐름

```
[1] 자동 분석 실행 → 부정확한 부분 확인
[2] "수동 보정 시작" 클릭 → 노란 EZ점 / 녹색 치아폭 끝점을 드래그로 정확히 수정
[3] "위치 저장 (파일 다운로드)" 클릭 → 수정된 md 파일 저장
[4] 저장한 md를 이 폴더( 04 수정본 수집 )에 넣기
[5] 재학습 순환 스크립트 1회 실행
[6] 개선 확인 → 모델을 HTML에 재반영
```

## 상세 절차

### 1~3단계: 브라우저에서 수정·저장
1. `EZ Curve - TZ Length - 보정 후 알고리즘 적용.html`을 열고 사진 업로드
2. **자동 분석 실행** → 결과가 부정확하면
3. **수동 보정 시작** → 틀린 EZ점/치아폭 끝점을 마우스로 끌어 정확한 위치로 이동
4. **위치 저장 (파일 다운로드)** → `<번호>.md` 파일이 저장됨

### 4단계: 수집
- 저장한 `.md` 파일을 이 폴더( `04 수정본 수집` )에 복사해 넣습니다.
- 여러 케이스를 모아서 한 번에 반영해도 됩니다(많을수록 학습 효과 큼).

### 5단계: 재학습 순환 실행
`03 AI 재학습` 폴더에서 (또는 프로젝트 루트에서 경로 지정):

```bash
node "03 AI 재학습/retrain_loop.mjs"
```

이 스크립트가 자동으로:
1. 수집본을 이미지 SHA-256 기준으로 EZ 정답(`02 이퀼리브리엄 찍기`)·치아폭 정답(`TS`)에 반영(원본은 `.bak` 백업)
2. 데이터셋 재빌드 → 규칙 베이스라인 → KRR 재학습 → 중첩 독립검증
3. `measure_engine`으로 정답 대비 오차 측정 → 개선 여부 출력

옵션:
- `--ingest-only` : 수집본 반영만 (재학습 안 함)
- `--measure-only` : 재학습 없이 현재 예측으로 측정만
- `--python <경로>` : Python 실행파일 지정

### 6단계: 모델 반영
재학습으로 오차가 개선되면 `residual-model.json`이 갱신됩니다.
이를 HTML에 다시 임베드해야 브라우저 자동 분석에 반영됩니다.
(임베드 절차는 세션에서 자동화 가능 — "KRR 모델 재임베드" 요청)

## 원칙
- **원본 정답은 항상 백업** 후 갱신됩니다(`.bak-<sha8>`).
- **개선은 measure_engine 수치로 검증**합니다. 감으로 판단하지 않습니다.
- 독립검증(`nested-policy-metrics.json`)이 배포 게이트를 통과해야 신뢰도가 높습니다.
- 자동 분석 결과는 항상 "초안"이며, 최종 판단은 의료진이 합니다.
